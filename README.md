# MEDI-EXPRESS

**Vos médicaments livrés à votre porte.**

MEDI-EXPRESS est un service de livraison de médicaments à domicile, basé à Libreville. Le client commande en ligne auprès d'une pharmacie partenaire et reçoit ses médicaments en moins de 2 heures.

## Ce que propose le site

- **Livraison rapide** : moins de 2 heures partout dans la ville.
- **Service 24/7** : une équipe disponible pour les besoins urgents.
- **Produits certifiés** : médicaments authentiques venant de fournisseurs agréés.
- **Sécurité et confidentialité** des données personnelles et médicales.
- **Catégories de médicaments** : douleur et fièvre, rhume et grippe, troubles digestifs, sommeil et stress, allergies, vitamines et suppléments.
- **Services** : envoi d'ordonnance, téléconsultation avec un pharmacien, conseils santé personnalisés.
- Un espace **Pour les pharmacies** partenaires.

## Aperçu

Ouvrez `index.html` dans un navigateur. Aucune installation n'est nécessaire.

## Mettre le site en ligne

**Netlify** (gratuit) : glissez le dossier du projet sur [app.netlify.com/drop](https://app.netlify.com/drop).

**GitHub Pages** : dans **Settings → Pages**, choisissez la branche `main` et le dossier `/ (root)`. La page doit s'appeler `index.html` pour s'ouvrir à l'adresse du site.
